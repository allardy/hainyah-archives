L'exode vous permet de changer de royaume quelque soit la raison. Cette opération vous coutera 1 points d'exode et vous aurez droit à 3 exodes maximum pour chaque ère. Pour avoir des exodes supplémentaires, vous devez en faire la demande à Shardok et avoir une bonne raison.

Voici les conditions pour s'exoder:

- Compte gratuit:

- Vous devez avoir fait au moins 57 heures de votre protection.

- Si vous avez une noblesse plus grande que vagabond, vous n'aurez pas à attendre ce délai pour faire une demande.

- Si vous avez une noblesse plus grande que vagabond, vous pourrez vous exoder sans demande à la fin de votre protection.

- Vous devez faire une demande d'exode. Si vous êtes accepté par le roi de ce royaume vous serez automatiquement exodé.

- Compte privilège:

- Si votre compte est activé, vous pourrez vous exodez dans le royaume de votre choix.

- L'exode sera instantanée.

Vous avez la possibilité de sélectionner le royaume où vous désirez vous exoder.

Vous avez la possibilité de faire un maximum de 35 exodes volontaires au cours de l'ère.

Veuillez noter qu'il est impossible de quitter votre royaume si vous avez des troupes en attaque ou si votre royaume est en état de guerre.

Royaume possible: 1:1 à 1:10 - 2:1 à 2:10 - 3:1 à 3:10 - 4:1 à 4:10

- Pénalitées

Un délais devra être respecté avant de s'exoder. Une pénalité sera appliquée pour ceux qui s'exodent trop rapidement. Le délais est fixé à 24h. Cette règle ne s'applique pas aux demandes d'exode qui doivent être validées par un roi.

Les pénalités sont:

- réduction de 20% xp de mage

- réduction de réputation de voleur

- réduction de 10% de chaque unités(guerrier. sentinelle, archer, élite, voleur)

- réduction de 75% des 3 ressources

Cette règle s'applique aussi pour les royaumes des dieux.

Comment faire une exode?:

Vous devez vour rendre sur la page option en cliquant sur Options du menu du jeu. Dans la partie Exode, Entrez la région, le royaume et votre mot de passe. Cliquez sur Confirmer ou Demander. (change selon votre type de compte)

Pour de meilleur résultat, communiquez par courrier avec le roi du royaume choisi en décrivant votre status, votre style de jeu et votre intention dans le jeu.

Après votre demande, le roi aura une brève descrition de votre seigneurie afin de juger plus directement si vous convenez au style du royaume. Si vous ne voulez pas montrer vos informations, envoyez un courrier d'abord et attendez les instructions du roi.

Comment accepter une demande d'exode?:

- Vous devez être roi pour accepter des demandes d'exodes. Voir GUIDE ROYAUME

- Appuyez sur F5 pour actualiser le menu.

- Cliquez sur le menu Exodes et choisissez parmis les demandes reçus.
