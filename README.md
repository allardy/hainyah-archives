# Archives HainyaH

HainyaH était un jeu de stratégie en ligne, gratuit et en français, créé au Québec en 2003 par Patrick Hains et Claude Hayfield, et fermé
vers 2016. Ce dépôt est le site de ses archives, servi par GitHub Pages : ouvrez `index.html`, ou visitez le site.

| Dossier | Contenu |
| --- | --- |
| `guide/` | Le guide des joueurs tel qu'il était en ligne de 2003 à 2010, avec le palmarès de chaque ère |
| `accueil/` | Dix-huit pages d'accueil, de portail, du domaine de l'Oracle et de Domination, de 2003 à 2012 |
| `galerie/` | Plus de 500 images du jeu |
| `remasters/` | Les images de 2010 à côté de leur remaster pour le nouveau HainyaH |
| `oracle/` | L'Oracle, le calculateur de combat des abonnés : les deux versions de 2009 |
| `jeu/` | L'interface de 2010, reconstituée sur une ère et une seigneurie fictives |

Les pages anciennes sont reproduites telles quelles, avec seulement ce qu'il faut pour qu'elles s'affichent aujourd'hui : l'encodage des
accents, les liens brisés et les images retrouvées ailleurs. Rien n'a été inventé pour combler un trou.
